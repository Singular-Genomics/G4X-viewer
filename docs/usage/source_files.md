This section describes how to load data into the G4X Viewer and manage the visibility of the available data layers.

## features

- <b><u>Cloud Upload:</u></b>

    With this button, you can paste a cloud storage link to stream the data into the Viewer in real time.

- <b><u>File Upload:</u></b>

    Here, you can upload a file from your locally accessible storage devices. Depending on the viewer version, you will either:

      - Upload a single **Zarr** file (available beginning with Version 4.0.0), or
      - Upload multiple files directly from the **g4x_viewer** output directory generated by the G4X pipeline.

      If using the legacy data and viewer versions, each file will contain a specific data layer or metadata component of the G4X assay:

      - **`<sample_id>.ome.tiff`** — Contains all protein images stored as a composite image.
      - **`<sample_id>_HE.ome.tiff`** — Contains the fH&E image.
      - **`<sample_id>.bin`** — Contains segmentation mask vertices.
      - **`<sample_id>.tar`** — Contains transcript locations.
      - **`<sample_id>_run_metadata.json`** — Contains sample and run metadata.

      For additional information about viewer-compatible output files, see the [g4x_viewer output documentation](https://docs.singulargenomics.com/g4x_data/output_files/g4x_viewer/).

- <b><u>Z-Layer Control:</u></b>

      Enables navigation between image Z planes in multi-dimensional image datasets. Standard G4X datasets typically contain a single Z-plane, so these controls are usually fixed or unavailable during normal use.

- <b><u>Manual Scaling:</u></b>

      This field controls the zoom level within the viewer by setting forcing the scale bar to represent a specific value. If zooming normally, the scale bar automatically updates as you zoom in and out of the image.

- <b><u>Overview Toggle:</u></b>

      Toggles on and off visibility of the image overview in the bottom left of the screen. This window displays the whole image in a thumbnail with the viewing area in a red rectangle to help understand your position on a sample when more zoomed in.

- <b><u>Layer Toggles:</u></b>

      Toggles on and off the visibility of image layers displayed in the viewer.

      - **Channel Settings:** Show or hide protein image layers.
      - **Brightfield Image Settings:** Show or hide the fH&E layer.
      - **Transcript Layer Settings:** Show or hide transcript dots.
      - **Segmentation Layer Settings:** Show or hide cell segmentation masks.
