## features

- <b><u>Viewer File Upload:</u></b>

      The File Upload section is the starting point for loading data into the G4X Viewer.

      Depending on the viewer version, you will either:

      - Upload a single **Zarr** file (available beginning with Version 4.0.0), or
      - Upload multiple files directly from the **g4x_viewer** output directory generated by the G4X pipeline.

      Each file contains a specific data layer or metadata component of the G4X assay:

      - **`<sample_id>.ome.tiff`** — Contains all protein images stored as a composite image.
      - **`<sample_id>_HE.ome.tiff`** — Contains the fH&E image.
      - **`<sample_id>.bin`** — Contains segmentation mask vertices.
      - **`<sample_id>.tar`** — Contains transcript locations.
      - **`<sample_id>_run_metadata.json`** — Contains sample and run metadata.

      For additional information about viewer-compatible output files, see the [g4x_viewer output documentation](https://docs.singulargenomics.com/g4x_data/output_files/g4x_viewer/).

- <b><u>T- and Z-Slice Control:</u></b>

      Enables navigation between image planes in multi-dimensional image datasets.

      - **T (Time) Axis:** Used for time-course image data.
      - **Z Axis:** Used for multi-level image stacks.

      Standard G4X datasets typically contain a single time point and a single Z-plane, so these controls are usually fixed or unavailable during normal use.

- <b><u>Image Scaling:</u></b>

      Controls the scale bar displayed within the viewer.

      You can manually specify the distance represented by the scale bar shown in the lower-right corner of the viewer. The scale bar automatically updates as you zoom in and out of the image.

- <b><u>Layer Toggles:</u></b>

      Controls the visibility of image layers displayed in the viewer.

      - **Segmentation Layer:** Show or hide cell segmentation masks.
      - **Transcript Layer:** Show or hide transcript locations.

      The protein image layer cannot be disabled because it serves as the base image to which all other layers are aligned.
